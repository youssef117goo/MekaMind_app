# MekaMind - منصة IoT الذكية للبرمجة البصرية

## 🎯 نظرة عامة

MekaMind هي منصة IoT متقدمة تتيح للمستخدمين البرمجة البصرية للشرائح الإلكترونية (مثل ESP32) بدون الحاجة لكتابة أكواد معقدة أو معرفة أرقام الـ Pins الفعلية.

## ✨ الميزات الرئيسية

### 1. نظام التجريد (Hardware Abstraction)
- **الإدارة** تحدد خريطة الـ Pins الفعلية لكل شريحة
- **المستخدم** يتعامل فقط مع أسماء منطقية (مثل "حساس الحرارة")
- **النظام** يترجم تلقائياً بين المستويين

### 2. نظام البلوكات المتقدم

#### 📦 بلوكات المداخل والمخارج (I/O)
- `📖 قراءة` - قراءة قيمة من مدخل (حساس)
- `⚡ تشغيل` - التحكم في مخرج (محرك/LED)

#### ⚙️ بلوكات التهيئة (Setup)
- `⚙️ تهيئة تليجرام` - إعداد بيانات البوت (Token + Chat ID)
- `🖥️ تفعيل الشاشة` - تهيئة شاشة OLED أو LCD

#### 🖥️ بلوكات الشاشة (Display)
- `📝 اكتب على الشاشة` - طباعة نص/قيمة في سطر محدد
- `🧹 مسح الشاشة` - تفريغ الشاشة
- `🔄 تحديث الشاشة` - تحديث العرض (لشاشات OLED)

#### ⏱️ بلوكات التدفق الزمني (Timing)
- `⏱️ نفّذ كل` - تنفيذ بلوكات بشكل دوري (Non-blocking)
  - يدعم: ثانية / دقيقة / ساعة
  - يقبل بلوكات داخلية (أفعال)

#### 🔗 بلوكات النصوص (Text)
- `🔗 ادمج النصوص` - دمج عدة قطع نصية/قيم
- `📄 نص ثابت` - نص ثابت

#### 🚀 بلوكات تليجرام (Telegram)
- `🚀 أرسل لتليجرام` - إرسال رسالة (مع Rate Limiting تلقائي)

#### 🔀 بلوكات المنطق المتقدم (Logic)
- `⚡ عندما تتغير حالة` - Edge Detection (ينفذ مرة واحدة عند التغيير)
- `🔀 إذا كان` - شرط منطقي
- `⏳ انتظر` - تأخير (Blocking)

### 3. مساحتا عمل منفصلتان

#### 📋 قسم التهيئة (Setup)
- يُنفذ مرة واحدة عند بدء التشغيل
- يحتوي على: تهيئة الشاشات، تليجرام، WiFi

#### 🔄 قسم التكرار (Loop)
- يُنفذ بشكل مستمر
- يحتوي على: المؤقتات، الشروط، الأحداث

### 4. مولد الكود الذكي

يولد كود Arduino كامل يتضمن:
- ✅ المكتبات المطلوبة تلقائياً
- ✅ تعريف الـ Pins بناءً على خريطة الإدارة
- ✅ Non-blocking timers (millis-based)
- ✅ Edge detection للحساسات
- ✅ Rate limiting لتليجرام
- ✅ تعليقات بالعربية تشرح كل جزء

### 5. نظام السحب والإفلات

- اسحب البلوكات من صندوق الأدوات إلى مساحة العمل
- البلوكات ذات الأيقونة `[⤵️]` تقبل بلوكات داخلية
- اسحب بلوكات الإجراءات داخل البلوكات الأب

## 💡 مثال تطبيقي: مراقبة مستوى السوائل

### السيناريو
مراقبة مستوى السائل وإرسال إنذار عبر تليجرام مع عرض على الشاشة.

### البلوكات المطلوبة

#### قسم التهيئة (Setup):
```
[⚙️ تهيئة تليجرام | Token: "..." | Chat ID: "..."]
[🖥️ تفعيل الشاشة | نوع: OLED I2C]
```

#### قسم التكرار (Loop):
```
[⏱️ نفّذ كل | 2 | ثانية]
  └─ [🧹 مسح الشاشة]
  └─ [📝 اكتب على الشاشة | المحتوى: "المستوى: " + قراءة المدخل 1 | السطر: 1]
  └─ [🔄 تحديث الشاشة]

[⚡ عندما تتغير حالة | المدخل 1 | إلى: إيقاف]
  └─ [🚀 أرسل لتليجرام | الرسالة: "تحذير: مستوى منخفض!"]
  └─ [⚡ تشغيل | المخرج 1 | الحالة: تشغيل]
```

### الكود المُولَّد
```cpp
#include <Arduino.h>
#include <Wire.h>
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>
#include <WiFi.h>
#include <WiFiClientSecure.h>
#include <UniversalTelegramBot.h>

#define BOT_TOKEN "YOUR_TOKEN"
#define CHAT_ID "YOUR_CHAT_ID"
#define SCREEN_WIDTH 128
#define SCREEN_HEIGHT 64

Adafruit_SSD1306 display(SCREEN_WIDTH, SCREEN_HEIGHT, &Wire, -1);
WiFiClientSecure net;
UniversalTelegramBot bot(BOT_TOKEN, net);

int lastState_2 = -1;
unsigned long lastTime_0 = 0;
const unsigned long interval_0 = 2000;
unsigned long lastTelegramTime = 0;
const unsigned long TELEGRAM_RATE_LIMIT = 60000;

void setup() {
  Serial.begin(115200);
  pinMode(2, INPUT);  // حساس المستوى (INP_1)
  pinMode(15, OUTPUT); // المضخة (OUT_1)
  
  if(!display.begin(SSD1306_SWITCHCAPVCC, 0x3C)) {
    Serial.println(F("SSD1306 failed"));
  }
  display.clearDisplay();
  display.setTextColor(SSD1306_WHITE);
  
  WiFi.begin("SSID", "PASSWORD");
  while(WiFi.status() != WL_CONNECTED) { delay(500); }
  net.setInsecure();
}

void loop() {
  // ⏱️ 2 ثانية
  if(millis() - lastTime_0 >= interval_0) {
    lastTime_0 = millis();
    display.clearDisplay();
    display.setCursor(0, 0);
    display.print("المستوى: " + String(analogRead(2)));
    display.display();
  }

  // ⚡ Edge detection: حساس المستوى
  {
    int currentState_2 = digitalRead(2);
    if(currentState_2 != lastState_2 && currentState_2 == LOW) {
      if(millis() - lastTelegramTime > TELEGRAM_RATE_LIMIT) {
        bot.sendMessage(CHAT_ID, "تحذير: مستوى منخفض!", "");
        lastTelegramTime = millis();
      }
      digitalWrite(15, HIGH); // المضخة
    }
    lastState_2 = currentState_2;
  }
}
```
